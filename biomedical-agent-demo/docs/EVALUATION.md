# 评测说明

## 范围

项目包含两组不访问外部模型的验证：

1. `tests/test_biomedical_agent.py`：覆盖正常问答、未知主题、安全拦截、模型超时、空响应、不安全输出和回答长度限制；
2. `tests/run_eval_cases.py`：读取 `biomedical_eval_cases.json`，覆盖正常主题、边界参数、临床决策和高风险请求。

评测用安全的模拟模型回答替换真实接口，因此结果反映的是本地编排、主题解析和安全规则，不代表真实模型的医学准确率。

## 运行方法

```powershell
python -m unittest discover -s tests -p "test_*.py" -v
python tests\run_eval_cases.py
```

## 解读限制

- 评测集规模较小，不能证明安全策略覆盖所有表达；
- 模拟回答不会衡量事实准确性、引用质量或真实服务稳定性；
- 上线前仍需增加真实模型回归测试、人工医学审阅、隐私检查和更大规模的对抗性安全评测。
